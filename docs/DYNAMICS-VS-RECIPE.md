## 3. 网络侧对照（业界怎么做）

- [Wwise — Using transition segments](https://www.audiokinetic.com/en/public-library/2026.1.2_9249/?source=Help&id=using_transition_segments)：
  段间切换用**专用过渡段**（transition segment + pre-entry / post-exit），不是单纯淡出。
  → 对应我们的 `section_gap`（段末渐弱）只是**一半**，缺"过渡段"这个中间态。
- [Adaptive music / Dynamic music（Wikipedia）](https://en.m.wikipedia.org/wiki/Dynamic_music)：
  vertical remixing（同段换层）与 horizontal resequencing（换段）—— 我们的 `arr` 开关属于前者。
- [AES 132（Fenton）](https://eprints.hud.ac.uk/id/eprint/13858/6/AES%20132_Fenton_complete2012.pdf)：
  讨论 fill 与 **audio drop-out** 的衔接 —— 与"极静段入口"是同一类问题。
- [MTOSMT（Ponce）](http://mtosmt.org/issues/mto.14.20.3/mto.14.20.3.ponce.pdf)：
  "回归开场材料"是最强的一阶结构信号 —— 对应 `theme_melody_reuse`（同名段共用旋律）。
- 响度的标准口径（integrated / short-term / true peak）：[core.ac.uk 595834593](https://core.ac.uk/download/595834593.pdf)。

## 4. 被实测推翻的假设（别再犯）

1. **"呼吸口的 mix 压太狠导致入口硬切"** —— ✗ 实测入口落差只有 **−1.9 ~ −3.6dB**，
   比 BGM35 的 −3.9dB 还小。原结构配方（已删 2026-09-24） 表明呼吸口**靠密度降、不靠音量**。
   （`new_song.py` 里那行 `mix × 0.42` 已按此删除 —— 否则新建曲会过冲。）
2. **"`section_gap` 太长会把判据的 pre 窗口包进去"** —— ✗ 改 2.0→3.0 把 `04/17/18` 的
   「A2」边界修好了（A2/A3 共用旋律，撑住了渐弱）。
3. **"极静段削平了高潮"** —— ✗ 第一版按位置硬挑确实削平了 08/09/10 的峰值 23~37%，
   但改成**逐候选试算、要求峰值不掉**后，18 首峰值 **100% 保留**。
4. **`section_transition` 那 4 处 FAIL 与我的改动无关** —— ✗ 改 `section_gap`、加 `ending_fade`
   前后读数**一字未变**（14.1/14.9/15.8/**−1.1**dB），是极静段入口的固有读数；
   `04` 的负值说明"前段渐弱到很低、极静段开头轻轻起来"，属**判据盲区**，不是硬切。

## 5. 落地位置（改这些，别改数据）

| 机制 | 在哪 | 说明 |
|---|---|---|
| 中段呼吸口 | `new_song.py` 的 sections 生成段 + `arr.density = 0` | 挑**对比段**（B/C，非 A 系、非首尾） |
| 收尾逐小节渐弱 | `song_engine.py` 段级 `arr.ending_fade`（已进 `ARR_KEYS`） | 段内最后 N 小节**二次衰减**到 0 |
| 段界留白/渐弱 | `patterns.section_gap`（现 **3.0 拍**） | 段末渐弱；短于 ~1s 会被混响尾巴填满 |
| 段级调式 | `sections[].mode` | 不写就退回画像 `base_scale`（旋律与和弦各走各的调） |

⚠ **手工设置会被全量重生成冲掉**（本会话踩到第 5 次）：唯一可靠位置是 `new_song` 的**默认逻辑**。
