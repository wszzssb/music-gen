### 7.10 ✅ "镫一下" = Piano 反拍短音的**力度**（同日第三轮，接在 §7.9 之后）

⚠ **§7.9 的修复让这个"镫"更明显了，两条必须一起看**：Melody 换成持续型后，
音头从 −26.3 → −32.8 dB（轻 6.5 dB），原本被旋律音头盖住的 Piano 反拍短音反而冒了出来。

**用户原话**："只检查前面几秒，还是有镫一下的" → 指认位置 = **0.385s**
（Intro 第 1 小节的 Piano 反拍音：音高 40 · 时值 0.215s = 0.28 拍 · 力度 42）。
同类音在 Intro 每小节一个（0.385 / 3.462 / 6.538 / 9.615s），**全曲 392 个**。

**消融（只动那一个音，其余一切不动）**：

| 版本 | 音头 | 突出度（相对前 200ms 背景） |
|---|---|---|
| A 原样 | −28.2 dB | +10.3 dB |
| **D 只降力度 42→26** | −31.8 dB | **+6.7 dB** |
| **E 只加长时值 0.28→0.6 拍** | −28.2 dB | **+10.3 dB（一字未变）** |
| C 两者都改 | −31.8 dB | +6.7 dB（= D） |
| B 删掉该音 | −33.6 dB | +4.9 dB（下界 = 剩下的就是旋律本身） |

⇒ **"镫"只跟力度有关，跟时值无关**。

⚠ **推翻了 `piano_part` 里的一条旧记录**：那里写着"2026-09-22 试过 0.75 拍 / 88 后撤回，
实测音频几乎没变 ⇒ 不是这条轨的时值/力度问题"。真实情况是**那次改错了维度**
（改的是时值，还把力度**往上**调到 88），而且量的是 4.64s —— **那不是这个音**
（是旋律的衰减尾巴）。本轮已在原地把那 6 行注释换成正确结论。

**修法**：新增 `patterns.piano_stab_vel` / `piano_stab_dur`（opt-in，**缺省 = 老行为逐字节不变**）
→ `piano_part()`，已进 `PAT_KEYS`。本曲设 `piano_stab_vel = 36`
→ 全曲 392 个反拍音 **58/64 → 36/42**（段首渐入后 26 = 消融里最优那档）。
`determinism_and_bytes` **PASS**（其他 29 首不受影响）。
结果：0.385s 音头 −28.7 → −31.6 dB、过冲 +7.1 → +3.7 dB、该处响段峰值 −28.2 → −31.3 dB。

**⚠ 一条工具坑**（本轮白跑一轮才发现）：mido 的 delta 转**绝对 tick** 时，
绝对时刻 = 累加**含自己**的 `time`；写成"先 append 再累加"会让全部事件整体偏一个 delta，
于是"改了 1 处"其实改错了音（症状是三版读数完全相同）。

**⚠ 另一条口径坑**：`突出度 = 音头 − 前 200ms 均值` 在**前面有静音**时会虚高
（6.538s / 135.8s / 160.4s 报 +17~+23 dB 属伪影，不是"镫"）——
要么把背景限制在"实际有声"的窗口，要么与该时刻的其他声部比。
