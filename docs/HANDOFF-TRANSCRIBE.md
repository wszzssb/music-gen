## 3. 下一步候选（**按期望收益排序**；每条都写清假设 · 做法 · 验收判据）

### 候选 A（首选）：残差驱动迭代转录（analysis-by-synthesis）
- **假设**：两个模型漏掉的音，在"**整段频谱未被解释的能量**"里仍然可见 —— 这比已证伪的"单音级谐波证据"高一个量级的信息。
- **做法**：① 现有最好装配出初稿 → ② `render_midi.py` 渲染 → ③ 与原曲对齐后取残差（**按频带/帧**，不是逐音） → ④ 只在"残差里该音高的能量显著高于同音高基线"的位置**补音** → ⑤ 再评估、迭代 2–3 轮。
- **验收**：`truth_eval.py <新.mid> --ref <真值> --warp`，看**非鼓音符级 F1 + 逐角色召回**是否同时上升（**召回涨而 F1 不涨 = 失败**，B1 已经证明"光涨召回"没用）。
- **风险**：GM 渲染 vs 原曲渲染的音色差会污染残差 → 先用**自家渲染的真值**当输入做一次对照（那时残差里只剩真漏音）。

  `piano_crnn.pth`（172MB）、`piano_conformer.pth`（628MB）—— 先花 20 分钟搞清它们各自的
  输入输出与权重来源（**先量单来源精度，再谈集成**）。
- 另有：`transcribe_audit.py`（pyin 基准）可当**低音/单音**的独立来源；人声轨可用工具链的
  `melody_profile.py`（他们自测比 pyin 准）做**单音跟踪**。
- **验收**：新来源单独 F1 必须 > 0.35（否则并集只会加假音，见第三轮 Rihanna vs Muse 的分化）。

### 候选 C：降复音（分轨）**配一个能判别真假音的尺子**

- ⚠ 已备好的脚本思路：`D:\test\pop_transcribe_audit_交付\tools\stem_eval.py`（V0–V3 四种装配）。

## 4. 必须遵守的纪律（这轮踩出来的，每条都有代价）

1. **尺子先行**：任何"提升/下降"的结论，必须先 `python scripts\truth_eval.py --selftest` 全 PASS。
   本轮四次翻车**全是尺子错**（tempo map 退化 / 峰位符号 / 派生文件过期 / 容差平台）。
2. **留出集**：6 首上看到的改善不做数；正式结论要留出集。
3. **别只看全曲平均**：一律**逐角色**（贝斯/旋律/和声/鼓）+ **逐段**看 —— 平均会把"哪一层塌了"抹平。
4. **度量口径三处固定**（`truth_eval.py` 已内置）：鼓**按通道 9** 判 · 鼓**按族**比 · 齐奏同音**两侧对称去重**。
5. **来源合并前先对齐**（同音高直方图峰位，实测来源间差 +3~+16ms；不对齐会按 0.1s 格重复计数）。
6. **单音级证据不当判别器**（力度/真假音都一样：逐音 ρ ≤0.42，只有乐句级可用）。
7. **归因别跳步**："召回低"的第一嫌疑按顺序是 —— 真值时间轴错 → 来源没对齐 → 度量口径 → 复音数 → 最后才是模型。
8. **听觉从没量过**：以上全是音符层读数；`docs\UNMEASURABLE-SOLUTIONS.md` 那 8 条同样适用。
