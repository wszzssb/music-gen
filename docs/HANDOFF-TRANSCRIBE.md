## 3. 第五轮做完的两件事（结论 + 为什么）

### 候选 A 残差驱动迭代转录 —— **对照成立，真实不成立**

- **做法**：plain 渲染真值→`ref.wav`；plain 渲染转录→`t0.wav`；取残差；**把残差当音频交给转录器**；
  丢掉"t0 已解释"的候选；`t1 = t0 ∪ 补音`；迭代。
- **两个必须的修正**（都踩过）：① 渲染电平旋钮是 **`-o synth.gain`**（默认 0.2），不是 `-g` ——
  写错会削波，**削波 = 非线性 = 残差前提失效**（坑 267）；② 残差要在**频谱域**取
  （Wiener 软掩蔽 + 参考相位），且**先把 t0 逐帧电平对齐到参考** —— 否则掩蔽形同虚设
  （实测 t0 渲染 RMS 只有参考的 **0.24 倍**，不归一时平均掩蔽度只有 0.16）。
- **成败由"判别器"决定，不由"残差造得多干净"决定**：同一份残差，
  **BP** → 补音精度 0.26/0.30（ΔF1 −0.011/+0.004）；**YMT3** → **0.58/0.64**（ΔF1 **+0.022/+0.037**）。
- **对照实验（自家渲染的真值）**：Muse 0.600→**0.622**、Maroon 5 0.555→**0.589**；
  **和声织体召回 45.7%→52.6%**（前三轮的墙第一次动）。
  ⚠ **但精度掉 0.079/0.058，超"≤0.05"的约束** ⇒ 按判据**不算过**。
  ⚠ **迭代 2–3 轮不再涨**（补音精度 0.46→0.30→0.18），**一轮到顶**。
- **真实素材（决定性）**：Gaga **−0.012** / Muse +0.016 / Maroon 5 −0.007 ⇒ **负结果**。
- **归因（本轮最值钱的一条）**：对照只排除了"两边 program 不同"这**一半**混淆，
  "**音源本身根本不同**"那一半排不掉，而它是主导项 —— 真实素材上补音精度从 0.46–0.64
  掉到 **0.13–0.40**，正好跌破盈亏线。**盈亏线可解析算**：
  补 k 个自身精度 p 的音，F1 上升当且仅当 `p > (2TP+FP+FN)/[2·系统总音数]`
  （实测 Muse 需 **p>0.30**、Maroon 5 需 **p>0.28**）。

## 4. 下一步候选（按期望收益排序）

### 候选 F（**首选**）：**在分轨上取残差**，而不是在全混音上
- **假设**：残差法失败的直接原因是"残差里混着别的乐器的音色失配能量"。
  **Demucs 单轨的复音数比全混音低一个量级**，残差里"未被解释"的部分更接近"真的漏了音"。
- **做法**：`htdemucs_6s` 分轨 → 对每条轨（piano/other/guitar/bass）**分别**做
  残差的渲染—相减—再转录 → 补音 → 与 YMT3 的对应角色并。
- **验收**：同一条命令 `truth_eval.py <新.mid> --ref <真值.mid> --warp`；看**非鼓 F1 与逐角色召回是否同时升**。
- **先量一件事再动手**：分轨后**单轨上的补音精度**能不能到 0.5（低于盈亏线就别做）。

### 候选 G：把盈亏线当**准入判据**用在任何"加音"手段上
- 任何"往已有转录里加音"的方案，**先量补音自身的精度**；`p < (2TP+FP+FN)/[2N]` 就别加。
- 这是本轮唯一可复用的**通用判据**，成本极低（一次 `note_f1(ref, added)`）。

### 候选 H：把两个没量成的模型跑起来
- `piano_conformer.pth`：从作者 GitHub 取新的模型定义（含 RoPE + Conformer），别 `pip -U`（会动 `.venv-ml` 的 torch）。
- `music_piano-v2.onnx`：用 `onnx` 改掉 `ConvTranspose` 的负 `pads` 再存一份，之后按普通 ONNX 用。

### 候选 E（**欠账，做正式结论前必做**）：留出集
- 现有全部阈值（盈亏线、0.35 门槛、各口径）都压在 **6 首**上。带真值的现成集：
  **Slakh2100**（多轨含鼓）/ **POP909** / **EGMD** / **MAESTRO**。取 **20–30 首**复验。

### 候选 D（换目标，仍成立）：别追"每个音都对"
- **骨架版**：只交付 **贝斯（召回 51–89%）+ 旋律 + 和弦**，明确放弃和声织体逐音还原。
- **两档交付**：高精度版 + 高召回"候选版"（每个音标出被哪些来源支持），让人耳 30 秒定夺。

## 5. 必须遵守的纪律（每条都有代价）

1. **尺子先行**：任何"提升/下降"的结论，必须先 `python scripts\truth_eval.py --selftest` 全 PASS。
   **五轮里五次翻车全是尺子错**（tempo map 退化 / 峰位符号 / 派生文件过期 / 容差平台 /
   **`abs(1-a)` 恒真的"不是同一版本"警告**）。
2. **留出集**：6 首上看到的改善不做数。
3. **逐角色看**：贝斯/旋律/和声/鼓分开报 —— 平均会把"哪一层塌了"抹平。
4. **口径固定**（`truth_eval.py` 已内置）：鼓**按通道 9** 判 · 鼓**按族**比 · 齐奏同音**两侧对称去重**。
5. **来源合并前先对齐**（同音高直方图峰位，实测来源间差 +2~+16ms）。
6. **单音级证据不当判别器**（逐音 ρ ≤0.42；本轮再证：手工梳统计量 AUC 0.64–0.66，
   **还不如**它）；**要判别就用模型**（同一份残差，BP 0.26 vs YMT3 0.58）。
7. **归因别跳步**："召回低"的第一嫌疑按顺序是 —— 真值时间轴错 → 来源没对齐 → 度量口径 →
   复音数 → 最后才是模型。
8. **扫描产物的文件名必须带全部变体参数**（坑 265：`hard30` 静默覆盖了冠军
   `maskn` 的产物，后续迭代从**最差**变体起步，全程零报错）。
9. **渲染完立刻量峰值与削波样本数**（坑 267）；**任何"警告"都要有一个"不该响"的用例**（坑 266）。
10. **听觉从没量过**：以上全是音符层读数；`docs\UNMEASURABLE-SOLUTIONS.md` 那 8 条同样适用。
