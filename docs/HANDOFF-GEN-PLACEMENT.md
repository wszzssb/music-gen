要对的是**该主题的均值量级**；102 那首连"末落点 ≥8 格"都只有 70.5%（门 65% 刚过）。

## 3. 已经**否掉**的两个猜测（别重复走）

- ❌ **"落点整体偏离画像"**：生成曲 0.298~0.379 vs **真实模板自身** 0.259~0.347 —— 同一量级，
  109 甚至比模板中位**更低**。所以"整体不像"站不住，要查的是**形状**。
- ❌ **"长音起在拍外"**：长音（≥0.75 拍）起在非整数拍的比例 —— 生成 **29% / 24% / 35%**，
  而模板 **73% / 35% / 75%**。生成曲反而比真实模板**更"在拍上"**。

## 4. 机制（代码层，本轮读到的）

- 落点在动机模式下主要来自 **`CELLS_BY_N` / `_make_cell` 这套固定候选表**（每小节 3~6 个落点的组合）；
  画像只从两条窄缝进来：① **`_decorate_cell`**（**每小节至多搬一个**装饰音到画像加权的弱格）
  ② 候选**打分**里的 `onset_tvd`（只影响"挑哪条候选"，不当门槛）。
- **`_cap_onsets`** 补音时只补**反拍八分格 2/6**；它认的"强拍"只有**格 0 与格 8** ⇒ 裁剪/补充都在
  把重心往拍内中后段推。
- **守卫只卡上界**：`t_melody_form_rules` 查的是 `g0 ≤ 22%`、`last8 ≥ 65%`、密度区间 —— **没有下界**。
  历史上这条是为治**旧版 g0 过高（25.7%）**而设的，现在**反向过冲**到 2.6%，一路不会被拦；
  而 `SKILL.md` 里记的真实值是**格 0 占比 12.9%**。
