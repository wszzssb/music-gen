## 4. 机制（**代码层读出来的，注意：没有消融证据**）

- 落点在动机模式下主要来自 **`CELLS_BY_N` / `_make_cell` 这套固定候选表**（每小节 3~6 个落点的组合）；
  画像只从两条窄缝进来：① **`_decorate_cell`**（**每小节至多搬一个**装饰音到画像加权的弱格）
  ② 候选**打分**里的 `onset_tvd`（只影响"挑哪条候选"，不当门槛）。
- **`_cap_onsets`** 补音时只补**反拍八分格 2/6**；它认的"强拍"只有**格 0 与格 8**
  ⇒ 裁剪/补充都在把重心往拍内中后段推。
- **守卫只卡上界**：`t_melody_form_rules` 查的是 `g0 ≤ 22%`、`last8 ≥ 65%`、密度区间 —— **没有下界**。
  历史上这条是为治**旧版 g0 过高（25.7%）**而设的，现在**反向过冲**到 3.7%，一路不会被拦；
  而 `SKILL.md` 里记的真实值是**格 0 占比 12.9%**。

⚠ **上面三条是"读代码 + 读注释"得到的**，本轮只量了**结果**（16 首 g0 都低），
**没量过每一处各贡献多少** —— 这正是下一步要补的。
