## 2. 本会话落地了什么（按用户诉求）

1. **任意 MIDI → `song.json`**（`scripts\midi_to_song.py`）：
   - Type 0 单轨多通道 → 按通道拆（音符 + CC/弯音）；
   - 多 tempo → 默认**拒绝**（列出每段），`--allow-tempo-change` 按**秒**重排；
   - 轨名/GM 音色映射 + `--map` 覆盖（冲突时打印）；
   - 音符全量进 `notes_extra`（带力度），CC/弯音进 `automation`（全局拍）；
   - 生成层由 `apply_restore_no_gen` 自动关。
2. **编辑器 ↔ 引擎双向**：
   - `POST /api/ed/to-song`：编辑器当前模型 → `songs/<名>/song.json`（含同名覆盖确认）；
   - `POST /api/ed/import` 新增 `song` 参数：曲库曲目一键在编辑器打开；
   - 导出器补 `pitch_bends`（导入 → 导出 → 再导入，弯音不丢）。
3. **automation 轨**：
   - `song.json` 顶层 `automation = {轨: {ccs: [[拍,CC,值]], pitch_bends: [[拍,值]]}}`；
   - `song_engine.validate_automation()` 校验（`load()` 与 `/api/song` 保存共用）；
   - `write_midi` 写 CC/弯音（`bgm_synth.write_midi` 新增第六项 `bends`）；
   - 点之间**线性插值**（`densify_points`/`densify_cc`，默认 1/16 拍；CC64 不插值）；
   - 段界 CC7 渐变 `patterns.mix_ramp`（opt-in，默认 0）。
4. **面板**：引擎面板底部「自动化」（canvas：左键加点/拖点/右键删/💾保存）；创作台「②b 从 MIDI 新建」；
   编辑器「→ 引擎」「📚 打开」；`/?song=<曲目>` 深链接。
5. **A/B 听感验证**：`AB-自动化\`（带/不带 automation 两版 + 逐段 RMS/基频读数）。

## 7. 踩过的坑（本会话真踩，别再踩）

1. **`import_midi` 暴露 `tempo_map` → `export_midi` 自动继承**：`truth_eval` 的"导入→改 bpm→导出"
   夹具变双 tempo，尺子自检 2 项 FAIL。修法：`import_midi` 不暴露、`export_midi` 显式
   `use_tempo_map=True` 才写、导入器直接问 `midi_probe.parse_full`。
2. **`/api/song` 的 events 用 `startswith('{')`**：`song_engine.load` 会先打 `[还原曲]…`，
   于是**所有还原曲**的 events 都是 None（卷帘/事件数据缺失）。改成从第一个 `{` 解析。
3. **automation 只写端点 = 阶跃**：用户原话"到 3 秒突然变大声不和谐不好听"。
   CC11 20→127 是 +35dB 瞬跳、弯音 +1→−1 瞬跳。修法：1/16 拍线性插值。
4. **`PAT_KEYS` 漏登记 = 静默忽略**：`mix_ramp`/`automation_step` 不加进白名单，
   引擎会打印"不认识，会被静默忽略"。
5. **`densify_cc` 的 def 行被误替换**（edit 锚点写错）：一度让函数体挂错位置。
6. **前端版本号**：改了 `app.js`/`style.css` 必须升 `?v=` + `run asset_versions.py --write`，
   否则浏览器用缓存旧文件（`frontend_versions` 守卫会红）。
7. **曲库归档后自检空转**：`song_dirs()` 空 → `songs_or_fail` 断言；跑自检前先恢复 1 首。

**踩到/记下的坑（本批）**

1. **子串断言会假绿**：守卫写 `"S.auto.rect" in js`，变异改名成 `S.auto.rectX` **仍然命中** ——
   要断言**赋值那句**（`S.auto.rect = {x0`）。同族 PITFALLS 285/349/365。
2. **文本变异对"已 import 的模块"无效**：`_text_mut(new_song.py)` 改了磁盘，
   但 `new_song` 早已在进程里 import 过 ⇒ 注入等于没注入（"未注入"也报 FAIL 就是这个）。
   模块级行为要用 `Mut(模块, 函数名, 包装函数)`。
3. **`measure_velocity --self-test` 的"可以"是假绿**：只看"有没有音 > −60dB"，
   空分轨的串音峰也能过（BGM36 bass −82.8dB 被判可校准）→ 已加整轨 RMS 门槛 −60dB。
4. **弯音 8192 会被引擎拒**（上限 8191）—— 探针第一版就这么崩的；`--depth 2` 正好顶到上限。
5. **自检夹具不要依赖曲库**：`harmony_add_contracts` 原来挑"曲库里 ≥4 段的曲目"，归档后必红；

6. **`melody` 的小节号是段内 0 基**（写成全局号 → 音静默不发声，自检当场报"≥ 该段小节数"）。
