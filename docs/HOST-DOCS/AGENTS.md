# 全局约定（对所有项目 / 所有对话生效）

## 沟通与推理语言

- **回答与所有面向用户的文字一律用中文**（实测有效：正文中文占比 ≈78%）。
- 思维链中文：persona 层已强制（见下"思维链接入点"）；**工作区指令压不动思维链**。
  实测加指令后中文占比 ~58%（此前多数 <10%）—— 强引导，非 100% 保证。
- 代码、命令、路径、标识符、专有名词保持原文，不为"中文"而硬翻。
- **简短优先**：能一句话说清就不写三句。
- 汇报只给：**结论 + 差距表 + 一句"还没验证什么"**，不复述中间过程。

## 省 token 与命令行引号

改动**一次列全再跑**；试错**先离线验证**；全量自检只在交付前/改过检查项时跑。
`pwsh -Command` 会吃掉半角双引号 → **文本落文件再传路径**（`git commit -F <路径>`）。

### ⚡ 本机 shell 约定（2026-09-17 定，用户明确要求换掉 PowerShell）

**`pwsh` 工具实际跑的是 Windows PowerShell 5.1** —— `>` 写出 **UTF-16**、
`Set-Content -Encoding UTF8` 写出**带 BOM** 的 UTF-8（`json.load` 会报错）、半角双引号被吞。
**一律改用 Git Bash**（踩坑清单与原因 → `~/.dsh/docs/SHELL-NOTES.md`）：
`& 'D:\software\Git\bin\bash.exe' '<脚本.sh>'`
（bash 5.3.15，已实测：中文输出正常、引号 `"'`$\\` 全部原样、重定向写出**真 UTF-8**、heredoc 可用）。
WSL 未安装发行版，不可用。

**约定**：
1. **多步操作一律落文件**：shell 逻辑写 `.sh`、数据处理写 `.py`（用 write 工具建，编码正确）；
   命令行只留最简单的调用，不带引号 / 重定向 / 变量。
2. bash 脚本开头固定：`export PYTHONIOENCODING=utf-8 LANG=C.UTF-8`（否则 Windows python 打印中文乱码）。
3. **读文件内容用 read 工具**（不要 `cat`）；**写文本用 write/edit 工具**（不要 shell 重定向）。
4. **过滤输出 ≠ 检查结果**：长流程要么不过滤（写日志再 tail），要么**先看退出码**
   —— `| grep` 会吞掉 traceback 还让管道返回 0（踩过，据此写下了错结论）。
   （Git Bash 无 `bc`，算术用 python/awk。）
5. **绝不用 PowerShell 改含中文的文本文件**。
