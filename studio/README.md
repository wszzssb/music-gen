# BGM Studio —— 可视化编曲面板（工具链自带）

**位置**：`<music-gen>\studio\`（就是本仓库的一个子目录，一切都在同一个文件夹里）。
驱动的是**本仓库自己的脚本**（`scripts\*`），面板不重写任何音频逻辑：改的永远是 `song.json`，
所以面板与 CLI（`make_song.py`）两条路结果一致。

## 启动 / 停止

```powershell
studio\start.cmd          # 双击也行：起服务 + 开浏览器（已在跑则只开浏览器）
studio\stop.cmd           # 按端口杀进程树
# 手动：<仓库>\.venv\Scripts\python.exe studio\server.py --port 8765 [--open] [--root <曲库>]
```
`http://127.0.0.1:8765`，只监听本机。交付物默认导出到 `<仓库>\export\<曲目>\`。

## 它能干什么 ↔ 背后是哪个工具

| 能力 | 面板操作 | 背后 |
|---|---|---|
| 按音轨制作 | 音轨卡：GM 音色号 / 音量 CC7 / 声像 / 音符数；段落里逐轨开关 + 逐段 CC7、力度 | `song_engine` 的 `programs/mix/arr` |
| **实时混音台** | 「⬇ 载入分轨」→ 分轨同时播放，推子/声像/静音/独奏/电平表；「↩ 写回」；「🔊 以当前混音渲染」 | `bridge stems` + WebAudio |
| **⚡ 试听本段** | 只渲染**当前段落切片**并循环（实测 1~3 秒）：改一版立刻听 | `tools/preview_job.py` |
| **🎚 自动配平** | 解方程求每轨 CC7（±6dB 护栏）→ 真渲染 → **实测成绩单** → 更好才留、更差自动回滚；到限幅时给"该改哪一轨"的建议 | `bridge mixfit` + `tools/mixfit_job.py` |
| **🧬 候选搜索** | 选段 + 速度档 → 切片渲染 + 多路并行 + 贪心搜索；结果出**逐项采纳表**（织体类预勾选、性格类标红），**默认不写回** | `tools/search_job.py` |
| 可视化写旋律 | 卷帘：全轨音符着色；**Melody 可增删拖**、拖右缘改时值、Alt+拖改力度；**和弦内音导引带 + 强拍违规描红** | `scripts\song_events.py` + `song.json` |
| 段落/和弦编辑 | 时间轴选段 → 小节数 / 每小节和弦 / 编排开关 / 混音；「🎹 和弦表」改和弦定义（实时校验可解析） | `song.json` 契约 |
| 指标 | 绝对倍频程差 + **占用率**（墙/点）+ RMS/宽度/质心；可按**时间窗**（引子/安静段/主体段/尾奏） | `bridge metrics`（同 `scripts\bands_abs.py` 口径） |
| 参考曲 A/B | 传输条切「主混音 / 分轨混音 / **参考曲**」，同位置、同循环区间 | `/api/ref-audio` |
| 播放/循环/波形 | 波形拖动定位，Shift+拖设循环，播放头画在卷帘上 | `engine.js` |
| 作曲/渲染/调参 | 🎼 作曲 / 🔊 渲染（+宽度校准）/ ✨ 渲染+调参（自动 EQ） | `song_engine` / `make_song.py` |
| 合并/分轨导出 | 📦 合并交付（MIDI+OGG+WAV+notes+song.json）/ 🎚 分轨（`stems/*.ogg`） | `bridge export --stems` |
| ➕ 新建曲目 | 脚手架：选模板/风格/参考画像 | `new_song.py` |
| 保存/校验/撤销 | 💾 规范写回 · ✅ 数据契约检查 · Ctrl+Z/Y（含音符级） | `json_io.py` / `check_song.py` |

## 速度（实测，都是这台机器上的真数字）

| 动作 | 耗时 |
|---|---|
| 候选搜索单次渲染 | **0.36 s**（8 小节切片；150BPM 歌） |
| 搜一轮（标准档 48 次预算 / 4 路并行） | **11 秒**（慢歌 67.6BPM 切片更长 ≈60 秒） |
| ⚡ 试听本段（4~8 小节） | **1~3 秒** |
| 整曲渲染（含宽度校准） | **18 秒**（238 秒的歌）~40 秒 |
| 整曲渲染 + 自动调参 | 2~3 分钟（只在定稿跑） |

速度靠三件事：**只渲染切片** + 多路并行 + 渲染预算/墙钟上限/⏹ 停止（`POST /api/stop`）。

## 边界（诚实）

- **只有 Melody 轨能手写音符**，其它轨由引擎按和弦+编排生成（改和弦/开关/CC7 才是正确改法）。
- 混音台推子是线性增益，写回按 `CC7 = gain×100` 映射；**写回后要重新渲染**才进 MIDI/成品。
- 🧬 搜索的适应度只衡量"更像参考曲"，不衡量音乐性 → **性格参数（律动/移调）必须人工确认**（默认不写回）。
- 指标只证明"像不像"，**好不好听只能靠耳朵**。
- 10-18k 的"连续空气墙"是音源天花板（见 `PITFALLS.md` 103）。
- 中间产物（分轨缓存/切片）都在 `%TEMP%\bgm-studio-audio\`，不进仓库。
