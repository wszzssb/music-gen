# BGM35 3:31–3:41 的四个探针（一次性脚本，**不是**一等工具）

**这里放的是**一次真实扒带任务里"用专用模型回答三个问题"用过的探针脚本 ——
它们**不进 `scripts/`**（那是引擎工具的位子，要配自检 + 变异用例），
只作为**可重跑的存档**留在这里：判据、参数、坑全在
`docs/HANDOFF-TRANSCRIBE.md` **§11** 与 `PITFALLS.md` **284–287**。

**什么情况下翻出来用**：真实录音里"某几秒听着不像"，且已经排除了混音层
（响度/频段/EQ）—— 也就是**要判内容真假**的时候。三条典型问题：
① 某分轨那几秒是**真内容**还是**分离残留**？② 旋律是不是**八度错**？
③ 那层音色是什么、GM 能不能近似？

## 跑之前要知道的三件事

1. **路径是写死的**（`D:\test\_tmp\b35\...`）。那个工作区**已随中间产物删除**，
   重跑要先重建：源 FLAC → Demucs 6 轨（`stems/htdemucs_6s/BGM35/`）→ 各来源转录（`src/`）。
   代价约 5 分钟（Demucs 37s + YMT3 三视图 ~3 分钟）。
2. **Python 用 `.venv-ml`**（torch / torchcrepe / librosa / demucs / transformers）。
   CLAP 权重 `laion/clap-htsat-unfused` 在 HF 缓存里，**要设 `HF_HUB_OFFLINE=1`**。
3. **先自检再量**：
   `q2_f0_rulers.py synth`（合成已知音高）→ `q2_f0_rulers.py render && q2_f0_rulers.py checksolo`
   （GM 已知 MIDI，即**天花板实验**）—— 自检不过，后面所有读数都不算数。

## 三个**反面**结论（省得下次重造）

- **起音共位率判不了串音**：drums 起音落在 other 起音 ±50ms 内在**真鼓窗也是 100%**。
- **线性泄漏 R² 判不了**：Demucs 软掩码不是线性混合，全窗都 ≤0.031。
- **逐起音"同在场音高数"判不了单线/和弦**：`other` 本来就是复音混合物，对照窗中位 6.0。
  ⇒ 判"真假"用**电平**与**谱平坦度**（见 `PITFALLS.md` 284）。

## 一句话纪律

**任何"差异判据"先拿一个"已知正常"的窗口跑，报出触发率；≈100% 或 ≈0% 就当场作废。**
