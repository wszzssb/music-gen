# 26 g114_intricate —— 复杂向器乐《Intricate》

**需求**：写一首**复杂**的 BGM，约 1 分钟（能力验证，第三首）。

| 项目 | 值 |
|---|---|
| 调性·速度 | **D 小调起、B 段转关系大调 F**，114.1 BPM，4/4 |
| 长度 | 28 小节 ≈ **63.3 秒**（成品 ogg） |
| 结构 | Intro 4 + A 8 + B 8 + C 8 |
| 和声 | Intro `Dm–Gm7–A7–Dm`；A 段 `Dm–Gm7–C7–Fmaj7–Bbmaj7–Em7b5–A7–Dm`（i–iv7–VII7–III–VI–**iiø**–V7–i，完整下行五度圈）；B 段 `F–Dm7–Gm7–C7–F–Bb–**G7**–C7`（转 F 大调 + 次级属）；C 段 `Fmaj7–**F#dim**–Gm7–C7–F–**Bbm6**–F/C–Fmaj7`（半音经过 + 借用 iv6） |
| 编配 | `style: gorgeous` —— 竖琴分解 + 弦乐 + 人声合唱垫 + 钢片琴 + 定音鼓/三角铁（+A 段起加 `harmony` 副旋律层） |

## 复杂度体现在哪三处

1. **和声**：A 段走完整下行五度圈 `Dm→Gm7→C7→Fmaj7→Bbmaj7→Em7b5→A7→Dm`，中间用到**半减七 `Em7b5`** 与 **`Bbmaj7`**（降低九度的色彩），不是常规的四和弦循环。
2. **转调**：B 段整体转到关系大调 **F**，并用 **`G7`（II7 次级属和弦）** 把 `Bb` 推向 `C7`，形成"离调再回来"的推力。
3. **半音**：C 段用 **`F#dim`（减三和弦）** 作半音经过（`F→F#dim→Gm7`），再用 **`Bbm6`（借用 iv6）** 做收尾前的色彩暗转，最后 `F/C` 转位落回主和弦。

编配上 A 段起启用 `harmony`（副旋律层，给旋律配和弦内低三度）、B 段加竖琴/琶音，C 段全轨满编 —— 段间对比靠层数而不是音量。

**客观硬指标**：强拍**全部落在和弦音上，严判据 0 条错音**（过程中严判据抓到并修掉了 3 处：`88(E)` 配 F 三和弦、以及一个把 D6 当成 F# 的音高笔误）。

## 未达标项（如实记录）

1. **315–1250Hz 厚 +10.7 / +12.0dB，质心低 967Hz** —— 本曲中频堆积、整体比参考暗。参考 BGM04 是"薄而亮"的织体，本曲是竖琴+弦乐+合唱垫+钢琴的**厚编配**，方向性差异。
2. **已按成绩单做了一轮编配修正**（`sub_gain` 0.5→1.6 补低频、中频四轨各降 8~12 个 CC7、`Glock` 提到 104 并加十六分 `air` 垫层）：
   - 见效：20–40Hz **−16.4 → −6.9**、40–80Hz **−6.5 → −2.2**（低频修好了）
   - **无效**：315–1250Hz 一动没动 → 说明该频段能量来自**竖琴/弦乐/合唱垫的织体本身**，不是这几轨的音量旋钮。这与库内 16 号曲 `notes.md` 记录的同类经验一致（当时降 `mix.Piano`/`mix.Hook` 各 10dB 也"一动没动"）。
   - 按项目规则「按成绩单改完最多再跑一次」，**到此停手**，不硬凑。
3. 20–40Hz 仍差 −6.9dB：厚编配的低频被中频掩蔽，属编配取向问题。

**性能**：自动调参 2 轮收敛（`mid_db` 到顶）。
