# 02 Drive Pop —— 仿 bgm01c.ogg（舞曲向）

| 项目 | 值 |
|---|---|
| 风格 | 128BPM 四踩底鼓 + 反拍踩镲 + 十六分贝斯的舞曲化流行，仿 `bgm01c.ogg` |
| 调性·速度 | **D 小调，128 BPM，4/4**，小节 1.875s（与参考曲同速同小节长） |
| 长度 | 64 小节 ≈ **120 秒** |
| 结构 | Intro 8 + A 16 + B 16 + A' 16 + Outro 8（前 8 小节铺底，之后满编到底） |
| 和声 | 主歌 `Dm–Bb–F–C / Dm–Bb–Gm–A7`（i–VI–III–VII / i–VI–iv–V7）；副歌 `Bb–C–Dm` |
| 编配 | 8 轨：主奏合成器 / 电钢琴反拍切分 / 八分琶音 / 暖 Pad / 弦乐 / 合成贝斯(十六分驱动) / 钟琴 / 鼓组 |

## 参考曲扒到的关键特征（本曲即照此写）

- 速度由低频周期性 0.96 锁定：**128 BPM / 1.875s 一小节**
- **低频节奏型**（16 分格）`★★◇·★★··★★◇·★★◇·` → 每拍**正拍+十六分双踩底鼓**，贝斯十六分驱动
- **高频节奏型** `◇·★◇·◇★◇◇·★◇·◇★◇` → ★只落在每拍后半拍 = **反拍踩镲**
- 调式：安静段音级 A D G A# D# → 开放五度 **D–A** 铺底 + B♭/E♭ 色彩 → D 为中心的小调
- 结构：前 8 小节 −20dB，之后全程 −14dB（无回落）

## 复现

```powershell
$py = "D:\software\skill\.venv\Scripts\python.exe"
cd D:\software\skill
& $py songs\02_dn128_drive\dn128_drive.py
& $py scripts\render_midi.py songs\02_dn128_drive\dn128_drive.mid dn128_drive_sf `
     --width 1.0 --rms -14.3 --shelf 2.5 --hp 42 --low 3.5 --drive 2.0
```

渲染参数说明：参考曲是**窄而响**的混音（宽度 0.316、RMS −14.3），所以加宽只用 ×1.0、
低频搁架 +3.5dB@150Hz 补 40–160Hz、42Hz 三阶高通切掉参考曲没有的 20–40Hz 轰鸣。
