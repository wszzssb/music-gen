# 28 d150_skip_along —— 原创欢快日常 BGM《Skip Along》

**用户需求**：写一首欢快的 BGM。
**开工前定下的两件事**（问过）：编制方向 = 日常轻快（钢琴+钢弦吉他+电钢+沙锤）；用途 = 游戏循环 BGM，100~140 秒。

| 项目 | 值 |
|---|---|
| 调性·速度 | **D 大调，150.0 BPM，4/4**（每拍 0.4s） |
| 长度 | 72 小节 ≈ **118.7 秒**（MIDI 115.2s + 混响尾） |
| 结构 | Intro 4 + A 8 + B 8 + C1 8 + A2 8 + B2 8 + C2 8 + Bridge 8 + C3 8 + Outro 4 |
| 和声 | 主歌 `D–D/F#–G6–A–Bm7–A/C#–Em7–A7`；预副歌 `G6–A7–F#m7–B7–Em7–A7–D–A7`；副歌 `G6–D–A–Bm7–G6–D–A7–D`；Bridge `Bm7–Gm7–D–A7–Bm7–Gm7–Em7–A7`；尾声 `G6–A7–D–D` |
| 编配 | **9 轨**，`style: daily` + 覆盖：原声钢琴主奏(GM0) / 电钢切分(GM4) / 钢弦吉他(GM25) / 颤音琴(GM11) / 暖 Pad(GM89) / 弦乐(GM48) / 原声贝斯(GM32) / 钢片琴(GM9) / 鼓组(沙锤+轻底鼓，ch10) |

## 创作说明（为什么这么写）

- **和声**：主歌用**卡农式低音下行 D–F#–G–A–B–C#**（I–I/3–IV–V–vi–V/3）——推动感强、色彩一路向上，是"欢快日常"最正的骨架；副歌换 **IV–I–V–vi** 的明亮释放。副歌音区比主歌**整体抬高六度**（主歌起音 74=D5 → 副歌 83=B5）。
- **Bridge 的转折**：借 D 大调的 **iv（Gm7）**做色彩暗转（这也是参考曲 BGM16c 的签名手法之一），再由 Em7–A7 推回终副歌，避免三遍副歌雷同。
- **旋律全新创作**（没有复制任何参考曲）：八分驱动的「短-短-长」跳跃动机。工具链自检判据：**强拍 144 个全部落在和弦音上 = 100% 弦内音，♭9 冲突 0**。
- **段落起伏**：Intro **满编不稀疏**（画像首段 −18 ≈ A 段 −17，做稀疏引子会让占用率崩，这是踩过的坑）；B 段进弦乐、副歌进琶音、终副歌加 `harmony` 层并把段落 CC7 推高（Strings 92 / Glock 92 / Perc 88 / Melody 104）；Bridge 收 vel 至 0.88 做对比。

## 未达标项（如实记录，未硬凑）

1. **160–315Hz 差 −2.7dB**（绝对口径 −5.0dB）。已把 `mix.Pad` 62→74 补厚度，只收回 0.3dB —— 说明这一带缺的不是 Pad 音量，而是原声小编制本身的中低音密度。再往上加会顶起已经接近参考的 315–630（+2.0），**故停手**。
2. **5000–10000Hz 差 −3.1dB、占用率 68% vs 参考 91%**（参考是"墙"，本曲是"点"）。这是**GM 音源的系统性天花板，不是本曲独有**：同画像的成熟曲 `16_d150_bright_day` 为 −4.1 / 70%，`21_g150_velvet` 为 −3.9 / 70%。共同解法要换音源，不是调参。
3. **低频/高频节奏型与参考不一致**：参考 BGM16c 是 150BPM **抒情向**（几乎无打击乐，高频靠弦乐持续音成"墙"），本曲是**沙锤+反拍贝斯**的轻快驱动编制，节奏型本就应当不同 —— 此处**不以参考为准**（技能口径：这是编配风格差异，不是缺陷）。
4. 响度 −17.5 vs −16.9（−0.6dB）：在容差内，未再追。

**性能与流程**：自动调参 2 轮内收敛（第一轮 4 轮收敛；补 sub/Pad 后第一轮即达标），未手开"渲染→测→调"循环。

## 2026-09-13 主旋律重写（治「同质化」，画像驱动生成）

**为什么**：用户反馈"这么多歌的主旋律都像"。根因不是照抄（跨曲共享片段只有 0.5%），
而是**旋律语言在复用同一套方言** —— 本曲原属 `BGM33`/`BGM16c` 那两批（5 首共用一份画像）。
详见 `HISTORY.md` 的「治本」一节与坑 109–113。

**做法**：`melody_gen.py` 已改成真读画像的**分布**（句长切成乐句并**句末留休止**、落点按
`onset16_hist` 的 16 格方言、时值按 `dur16_hist`、音程按 `interval_hist`），并按**本曲和弦**
推断大小调（不再写死小调）；本曲分到画像 **`psg_BGM16b`**（十首各一份、互不重复），seed 23，
8 条候选中按"与库里已有旋律最不像"取一条。

**复现**：
```
& $py scripts\melody_gen.py songs\23_d150_skip_along\song.json refs\melody\psg_BGM16b_melody.json --seed 23 --avoid songs --candidates 8
& $py scripts\make_song.py 23_d150_skip_along
```

**结果**：288 音 / 72 小节；强拍（第 1、3 拍）落和弦音 **100%**（74 个样本）；
落点格 **11** 种、正拍 45%；级进 72%、同音重复 41%。
全库"孪生对（旋律语言重合 ≥85%）"由 5 对降到 **0 对**（`probe_melody_lang.py`）。

**还没验证的**：听感 —— 客观指标只能证明"与其它九首不再说同一种话"，好不好听只能人听。
