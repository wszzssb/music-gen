# 05 Cheerful —— 欢快曲（仿 BGM18b.ogg）

| 项目 | 值 |
|---|---|
| 风格 | 欢快 / 轻编制，仿 `BGM18b.ogg` |
| 调性·速度 | **D 大调，134.7 BPM，4/4**（小节 1.782s，与参考同速） |
| 长度 | 32 小节 ≈ **51 秒**（参考 44.7s 同量级） |
| 结构 | Intro 4 + A 8 + B 8 + A' 8 + Outro 4 |
| 和声 | 主歌 `D–A/C#–Bm7–G–D–A–G–A7`；副歌 `G–A–F#m7–Bm7–G–A–D–A7`；尾奏 `G–A–D6/9` |
| 编配 | 7 轨：钢琴主奏 / 钢弦吉他分解 / 钢琴反拍 / 弦乐 / 原声贝斯（**反拍驱动**）/ 钟琴 / 轻打击 |

## 参考曲扒到的关键特征

- 134.7 BPM / 44.7s / **RMS −22.1dBFS（很轻）** / **宽度 0.818（极宽）** / 质心 1971Hz
- **频谱重心在中频**：最强段是 315–1250Hz，40–80Hz 只有 −11.8dB（不是低音主导的曲子）
- **高频极稀疏**：高频节奏型 `···◇····★··★····`（几乎没有镲）
- **低频反拍驱动**：`◇★◇★◇◇◇·◇★◇◇◇◇·◇` → 重音在每拍第 2、4 个十六分（0.25/0.75/2.25/3.25 拍）
- 调式 D 大调（全曲音级 D1.00 A0.86，小调特征音 A#/F 都很弱）

## 这版的编配是 JSON 数据驱动的

`song.json` 里选风格即可，不用改代码：`bass_style: offbeat`（反拍驱动）、
`perc_style: light`、`sub_gain 1.5 / sub_dur 0.55`（sub 用短音，长音会把节奏型糊成块）。
`compose.py` 只有 10 行，只是调 `scripts/song_engine.py`。

## 文件

- `d135_cheerful.mid` —— 主交付（9 轨 GM 音色 + CC10 声像/CC7 音量）
- `d135_cheerful_sf.ogg` / `.wav` —— 真音源成品
- `d135_cheerful.ogg` / `.wav` —— 自写合成器试听版
- `song.json` —— **编配数据（改这个）**；`render.json` —— 渲染参数；`compose.py` —— 固定桩
