## 这一轮的核心：把"像不像"量化成**占用率**，再把缺口补掉

判据不是频段能量（那早就对齐了），而是"**每个频带有没有一直在响**"。
口径：整混音 mono，帧能量 > 该带峰值 −25dB 的帧占比（`scripts/stem_compare.py`，前 40 秒 / 40–80 秒）。

| 频带 | 例曲 | 修补前 | **修补后** |
|---|---|---|---|
| 40Hz | 95 / 92 | 86 / 87 | **91 / 93** |
| 80Hz | 95 / 93 | 83 / 87 | 85 / 89（**仍差 4~6**） |
| 2500Hz | 87 / 99 | 90 / 93 | **97 / 97** ✓ |
| 5000Hz | 88 / 99 | 81 / 78 | **97 / 91** ✓ |

怎么补的（**都没换音源** —— 因为真的换不了，见下节）：

1. **kick 垫层**：`sf2_lib.py --drums` 量出 GeneralUser GS 的底鼓采样只有 **0.14~0.18 秒**，
   而低音嗵鼓有 **0.60~0.67 秒** → 在**底鼓的位置**叠 41/43 号嗵鼓补低频尾巴。
   位置由引擎里的 `kicks` 派生（**逐点对齐**，错位就变成两个鼓打架）。
2. **air 垫层**：每十六分一个开镲（46），补 2.5–10kHz 的时间覆盖。
   **连续性取决于"采样长度 vs 网格间隔"，不是 MIDI 时值写多长** —— 改成每八分只有 84%。

## 音源：换不了，所以把现有的用到极限

| 通道 | 结果 |
|---|---|
| GitHub / raw / jsDelivr / ghproxy | ❌ 全部超时 |
| archive.org / huggingface / keymusician（FluidR3 官方） | ❌ 连接超时 |
| PyPI / npm | ✅ 通，但**没有音源**：`arachno`（协程 DSL）、`sf2`（文件共享工具）、`generaluser`（就是本机已有的那个）|

留的口子：把 `.sf2`/`.sf3` 丢进 `vendor/`，`find_sf2()` 会自动优先使用它（认扩展名 + 名字里的质量提示）。
读音源的工具：`scripts/sf2_lib.py --drums`（列每个鼓组每个键的采样名与秒数）、`scripts/kick_probe.py`。

## 顺手修掉的一个真 bug：末尾 15.7 秒死气

重叠的开镲（0.4 拍 > 0.25 格距）让 FluidSynth 在 MIDI 结束后多渲染 **15.7 秒**的
**−72dBFS** 死气 —— 4:42 的歌变成 5:03，而且"多出来的时长"会被所有统计当成内容。
修法 `render_midi.trim_tail()`：**只在尾巴 >3 秒时才裁**，正常混响尾巴（既有 13 首实测 2.0~3.7 秒）一个字节都不动。
守卫：自检 `trim_tail` / `no_long_silent_tail` / `render_duration_matches_midi`。

## 还没做到（诚实清单）

- **80Hz 占用率**差 4~6 点（89 vs 93）：GM 的低频采样又短又干，"又连续又有颗粒"这一层到顶了。
- **瞬态冲击力**（峰值因数 17.8 vs 例曲 15.9 已接近；20ms 电平起伏仍是软的）是**音源问题**，不是编配问题。
- **低频节奏型**与例曲不一致（`★◇·★★··★` vs `◇★◇★◇★◇★`）：为补低频连续性在正拍加了垫层，
  能量重心偏向正拍 —— 这是"连续性"与"反拍推动"之间的取舍，本轮选择了连续性（它是"像不像成品"的主判据）。
- **5000–10000Hz 能量** raw 版仍高 3.4dB（matchering 后回到 +0.3dB）。

## 2026-09-13 主旋律重写（治「同质化」，画像驱动生成）

**为什么**：用户反馈"这么多歌的主旋律都像"。根因不是照抄（跨曲共享片段只有 0.5%），
而是**旋律语言在复用同一套方言** —— 本曲原属 `BGM33`/`BGM16c` 那两批（5 首共用一份画像）。
详见 `HISTORY.md` 的「治本」一节与坑 109–113。

**做法**：`melody_gen.py` 已改成真读画像的**分布**（句长切成乐句并**句末留休止**、落点按
`onset16_hist` 的 16 格方言、时值按 `dur16_hist`、音程按 `interval_hist`），并按**本曲和弦**
推断大小调（不再写死小调）；本曲分到画像 **`fine_BGM16`**（十首各一份、互不重复），seed 14，
8 条候选中按"与库里已有旋律最不像"取一条。

**复现**：
```
& $py scripts\melody_gen.py songs\14_d75_pulse\song.json refs\melody\fine_BGM16_melody.json --seed 14 --avoid songs --candidates 8
& $py scripts\make_song.py 14_d75_pulse
```

**结果**：176 音 / 88 小节；强拍（第 1、3 拍）落和弦音 **100%**（50 个样本）；
落点格 **9** 种、正拍 34%；级进 42%、同音重复 20%。
全库"孪生对（旋律语言重合 ≥85%）"由 5 对降到 **0 对**（`probe_melody_lang.py`）。

**还没验证的**：听感 —— 客观指标只能证明"与其它九首不再说同一种话"，好不好听只能人听。
