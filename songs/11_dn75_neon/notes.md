# 11 Neon Run —— 明亮驱动型舞曲（仿 BGM33.ogg）

| 项目 | 值 |
|---|---|
| 风格 | **`dance`（本工具链第一次用这套风格）**：合成主奏 + 电钢琴切分 + 琶音层 + 合成贝斯 + 四踩底鼓 |
| 调性·速度 | **G 小调（自然小调，D7 处带和声小调色彩），75.0 BPM，4/4**（小节 3.200s，与参考同速） |
| 长度 | **96 小节 ≈ 5 分 13 秒**（成品 313.5s，含混响尾） |
| 结构 | Intro 8 + A 16 + B 16 + A' 16 + C 16(breakdown) + B' 16 + Outro 8 |
| 和声 | A 段 `Gm–B♭–E♭–F` 骨架，后半 `Cm7–Dm7–E♭–F` 推动；B 段 `E♭–B♭–F–Gm` 上行 + `Cm7–D7` 属七回主；C 段（**鼓组退下的 breakdown + 关系大调提亮**）`B♭maj7–E♭maj7–F–B♭ / B♭maj7–Gm7–E♭–F`；尾奏 `E♭–B♭–F–Gm / E♭–D7–Gm–Gm7` |
| 数据量 | 96 小节只写 **188 个唯一旋律音符**（段落按名复用旋律，B' 用 `melody_extra` 加花）—— `song.json` ≈1.9k tok |

## ⚠ v1 被否掉过，这里是问题的客观成因（"不好听"是可以查的）

v1 的听感问题不是口味差异，解剖出来三条硬伤：

| 症状 | 实测 | 修法 |
|---|---|---|
| **旋律与和声打架** | 强拍只有 **54%** 落在和弦音上（早期曲目 78~87%），32 处与和弦音差半音 | 重写全部旋律：**强拍全部用该小节和弦的音**（现在 **100%**、♭9 = 0），经过音只放弱拍 |
| **大段原地踏步** | A 与 A' 的"旋律+和弦+配器"**完全一样**，96 小节里 52% 的旋律小节重复 | A' 换成新旋律 `a2`；新增 C 段 breakdown（鼓组退下 + 关系大调）作对比 |
| **主奏被伴奏糊住** | 旋律与伴奏挤在同一个八度（均值 67.8 / 65.2） | 旋律整体抬高到 70–84（伴奏 41–67），音区分离 |
| 音色刺耳 | dance 预设的锯齿主奏 GM81 | 主奏换 **GM82（柔和合成主音）**、琶音换 **GM11（音乐盒）** |

这三条已做成永久守卫：自检项 `melody_chord_fit`（强拍和弦音 ≥70%、♭9 ≤2 处，
弱拍不限制）+ 两条注入用例；**10_b146_night_meal 的旋律也一并修好了**（55% → 100%）。

## 为什么选这个风格与调性

参考曲画像（`refs/BGM33.json`）：**75.0BPM / 257s / RMS −15.9（很响）/ 宽度 0.404（窄）/
质心 3665Hz（很亮）/ 器乐**；低频节奏型 `◇★◇★◇★◇★·★◇★◇★◇★` = **反拍驱动**；
安静段根音集合 G–B♭–C–D → **G 小调**（无 A 自然音主导，故按自然小调写，只在 D7 用导音 F#）。

→ 与我前面做的 `ballad`（10 号）和 `daily`（05/06/09）完全是另一种编制，**这是刻意的换风格**：
明亮合成主奏 + 四踩 + 反拍贝斯，对应参考曲"亮、响、窄、驱动"的性格。

## 实测对比（vs 参考，按 `align_bands` 全频段对齐 —— 器乐参考曲不豁免任何段）

| 指标 | 本曲 | 参考 | 差 |
|---|---|---|---|
| 速度 | 75.0 BPM | 75.0 | 0 |
| **立体声宽度** | **0.404** | **0.404** | **0.000** |
| 响度 RMS | −16.2 | −15.9 | **−0.3** |
| 频谱质心 | 3332 Hz | 3665 | −333 |
| **80–160Hz（双方最强段）** | **0.0** | **0.0** | **0.0** |
| 20–40 / 160–315 | −16.2 / −2.9 | −17.4 / −3.5 | +1.2 / +0.6 |
| 40–80 | −0.9 | −3.9 | +3.0 |
| 315–630 | −2.1 | −6.0 | +3.9 |
| **630–1250Hz** | −1.6 | −8.3 | **+6.7**（唯一超过 4dB 的段） |
| 1250–2500 / 2500–5000 | −10.4 / −11.4 | −9.3 / −11.9 | −1.1 / +0.5 |
| 5000–10000 / 10000–18000 | −13.5 / −19.0 | −16.3 / −18.8 | +2.8 / −0.2 |

自动调参 4 轮达标（如实报"到顶"）。**唯一没贴合的是 630–1250Hz 偏亮 6.7dB**：
参考曲在这段是"挖空"的（80–160 很厚、400–1000 反而凹），而我们**EQ 链里没有覆盖
630–1250 的参数**（`low` 是低频架、`mid_db` 从 1.2kHz 起、`shelf` 从 3kHz 起），
只能靠改编配 —— 已经把 Melody/Hook/Piano/Arp/Strings 一路压到 56/42/54/34/42
（再压就开始发空），所以到此为止，如实记录。

调参过程中踩到并记录在案的坑：改配器后 `render.json` 里旧调参留下的极端 EQ
（`shelf +10 / mid_db +10 / low −2.7`）会把新一代带偏，导致 40–160Hz 塌 12~14dB
——**改完配器必须把 EQ 重置成中性再跑**（见 `PITFALLS.md` 坑 68）。

零削波、无直流、安静段干净（`noise_probe`：最静段 6–16kHz −67dBFS 级、谱平坦度 0.048）。
