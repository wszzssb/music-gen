# 12 Warm Run —— 暖声驱动型（仿 BGM33.ogg · **方案1：不用合成音色**）

| 项目 | 值 |
|---|---|
| 风格 | `daily` 预设 + 舞曲节奏：**钢琴主奏（GM0）+ 钢弦吉他（GM25）+ 电钢琴（GM4）+ 竖琴（GM46）+ 弦乐 + 原声贝斯（GM32）+ 四踩鼓组**；**刻意不用**合成主奏(GM81/87)、合成贝斯(GM38)、合成 pad(GM89) |
| 调性·速度 | **G 小调，75.0 BPM，4/4**（小节 3.200s，与参考同速） |
| 长度 | 80 小节 ≈ **4 分 22 秒** |
| 结构 | Intro 8 + A 16 + B 16 + A' 16 + C 16 + Outro 8（和弦**两小节一变**：A 段 `Gm Gm \| E♭ E♭ \| B♭ B♭ \| F F \| Gm Gm \| E♭ E♭ \| Cm7 Cm7 \| D7 D7`） |
| 数据量 | 80 小节只写 **188 个唯一旋律音符**（A' 用新旋律 `a2`，其余段落按名复用），`song.json` ≈1.9k tok |

**为什么是"方案1"**：11 号曲被否掉后，除了旋律/结构问题，还有音色——参考曲其实是"亮、响、厚低音"的
流行编制，用合成主奏+合成贝斯去凑只会更像电音。这一版把主奏与贝斯换成钢琴/电吉他/原声贝斯，
**只保留参考曲真正决定性格的东西**：反拍驱动的十六分贝斯 + 四踩鼓组 + 明亮的顶频。

## 这一版顺带验证了前几轮修的东西

| 修复 | 验证结果 |
|---|---|
| 旋律强拍必须落和弦音（新守卫 `melody_chord_fit`） | **渲染前**就抓到 2 处不合弦（98%）→ 修成 **100%**、♭9 = 0，**没浪费一次渲染** |

| 长曲必须后台跑（坑 65） | 4:22 的歌全程后台，单轮渲染 ~30s，无残留 `*.raw.wav` |
