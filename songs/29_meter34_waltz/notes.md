# 29 meter34_waltz —— **3/4 圆舞曲探针**（拍号能力的端到端验证）

**需求**：`README` 诚实清单第 3 条写着"引擎到处假设 4/4，3/4、6/8 未支持"。修完 A 档后，
用**一首真曲子**把 3/4 走通，而不是只跑合成信号。

| 项目 | 值 |
|---|---|
| 调性·速度 | **D 小调，150.0 BPM（四分音符），3/4** |
| 长度 | 24 小节 × 3 拍 ≈ **28.8 秒**（成品 ogg 34.0s，多出的是 FluidSynth 混响尾 ~4.8s） |
| 结构 | A 8 + B 8 + A2 8 |
| 和声 | `Dm–Bb–Gm–A`（i–VI–iv–V）；B 段 `Bb–Gm–A–Dm` 移到 VI 起 |
| 编配 | `bass_style: waltz` + `perc_style: waltz`（圆舞曲写法）+ 钢琴/电钢的 pah-pah；B 段加 Pad、钢片琴、副旋律 |

## 这首曲子要证的四件事（都过了）

| 判据 | 实测 |
|---|---|
| MIDI 拍号元事件写对 | `timesig=(3,4)`（修复前：`midi_probe` 永远读不出拍号，一律报 4/4） |
| 音符不越出小节、时长与谱面一致 | MIDI 末音 72.92 拍 = 29.17s，谱面 24×3 拍 = 28.80s（+0.4%） |
| 律动真的是"三拍一循环" | 按三拍折叠的起音强度：第 1 拍 **2.83** / 第 2 拍 2.49 / 第 3 拍 2.45 |
| **是地道华尔兹、不是"4/4 缩放版"** | 贝斯落点 `{0.0, 2.0}`（"oom"）、钢琴和弦 `{1.0, 2.0}`（"pah-pah"）、底鼓只在 `0.0`、侧棒在 `{1.0, 2.0}` |
| **旋律有呼吸**（不是每拍都塞满） | **2.12 音/小节**、最长 3 拍、时值 3 种、句尾留白 1 处、占空比 **33%**（初版：3.0 音/小节、最长 2 拍、**占空比 100%**） |

**强拍口径**：3/4 的强拍是**第 1 拍**（第 2、3 拍是弱拍）—— 本曲 24 个强拍**全部落在和弦音上**
（88% 是自检按全库口径打印的数字；本曲严判据 0 条错音）。

## 未达标 / 已知边界（如实记录）

1. **参考曲与速度不匹配**：这首是**能力验证曲**，参考 `BGM18b`（134.7BPM）只是拿来跑通对标
   流程，成绩单会照常报"速度不一致" —— 不是缺陷，是没为它挑参考曲。
2. **10–18kHz 亮 4.4dB**：自动调参提示"EQ 到头了，靠编配"（`mix.Glock`/`mix.Perc` 都在 70）。
   探针曲不追这一项。
3. **分析侧仍只支持 4/4**（这是本轮**故意**留下的边界）：成绩单里的"低频/高频节奏型"是按
   **4 拍一小节**折出来的，对 3/4 曲子**读数无意义**（打印出来的是 16 格，而本曲一小节 12 格）。
   同理 `probe_style.py` / `analyze_sections.py` / `melody_gen.py` 都会拒绝或算错非 4/4 ——
   已在 `profile_ref.py --meter` 与 `melody_gen` 入口处做成**显式拒绝**。
4. **第一版是"机械缩放"、不是华尔兹**（已修，记在这里当教训）：初版贝斯踩"第 1 拍 + 第 3 拍"、
   钢琴落在反拍 0.5/1.5 —— 那是把 4/4 的落点按拍号缩放，听感没有圆舞曲的推动感。
   现在有了 `bass_style/perc_style: waltz` 与钢琴的奇数拍分支（守卫：自检 `waltz_groove`
   + 变异用例"和弦退回 4/4 反拍写法 → 必须被抓"）。
5. **初版旋律"没有停顿"**（已修，**用户听出来的**）：初版 24 音 / 8 小节 = 每拍一个音、最长 2 拍、
   **占空比 100%、间隙 0** —— 正是自检 `melody_breathing` 说的"每拍都有新音且无长音/静音，听感会累"。
   重写后：句尾留 3 拍长音、第 6 小节第 2 拍留白，占空比降到 33%。
   顺带发现**那条检查自己也有 4/4 假设**（`tot += bars * 4.0`）→ 对 3/4 曲子把密度算小 1/3、
   差点漏掉本曲；已改成按拍号算（`song_engine.bar_beats`）。
6. **B 段换了和弦就要换旋律**：初版 B 段（`Bb–Gm–A–Dm…`）直接复用 A 段的旋律骨架，
   第 3 小节强拍 G 落在 A 和弦上属弦外音。现在 B 段用独立的 `mB`（强拍全在弦内音）。
